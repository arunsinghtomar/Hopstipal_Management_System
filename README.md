# 🏥 Hospital Management System (Python OOP Project)

## 📌 Project Overview

This is a simple **Hospital Management System** developed using **Python** and **Object-Oriented Programming (OOP)** concepts.
The project demonstrates how real-world entities like hospitals, doctors, and patients can be modeled using classes and objects.

---

## 🚀 Features

* 🏥 Hospital details management
* 👨‍⚕️ Doctor registration
* 🧑‍🤝‍🧑 Patient registration
* 🔍 Doctor specialization handling
* 📅 Appointment booking
* 📋 View all doctors
* 📋 View all patients

---

## 🧠 Concepts Used

This project is designed for beginners to understand OOP concepts:

* Classes & Objects
* Constructors (`__init__`)
* Methods
* Composition
* Lists (Data Storage)

## ▶️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/hospital-management-system.git
```

2. Navigate to the project folder:

```bash
cd hospital-management-system
```

3. Run the Python file:

```bash
python Hospital_Management_System.py
```
